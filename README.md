# مجتمع مالينز 

## متغيرات البيئة في Vercel

| المتغير | من أين |
|---------|--------|
| `TURSO_DATABASE_URL` | Turso → قاعدة البيانات → Overview |
| `TURSO_AUTH_TOKEN` | Turso → Create Token |
| `IMGBB_API_KEY` | https://imgbb.com → Account → API |

## إعداد imgbb (مجاني)

1. سجّل على https://imgbb.com
2. اذهب لـ **Account → API**
3. انسخ الـ **API key**
4. أضفه في Vercel كـ `IMGBB_API_KEY`
